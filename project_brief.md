# My agent: travel-planner-agent
One-liner: A conversational travel concierge agent that helps travelers plan personalized trips with destination guides and visual itineraries.

Tool coverage:
- Memory: Remembers user travel preferences, budget limits, dietary preferences, and saved destinations
- Tools: Looks up flight and hotel options, local weather, and destination activities
- Catalog/UI: Collection of travel itineraries, city guides, and accommodation listings rendered as cards and tables
- Image gen: Generates scenic images of recommended travel destinations and attractions
- Sandbox: Calculates trip budgets, multi-currency conversions, and itinerary time allocations

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): code sandbox for budget calculations, Cloud Trace
